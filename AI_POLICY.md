# AI policy

Galar Native is source-available, not open source. You can read the code here, but the [license](LICENSE) does not allow copying it, reworking it or using it to train AI.

## What is not allowed

- **Training:** using this repository, or any part of it, to train, fine-tune or evaluate a machine-learning model, or to build a dataset for one. This applies to research use too.
- **AI reworks:** having an AI assistant or agent reproduce, translate, port or rework this code, or a substantial part of it, for use outside this repository. That covers forks, other emulators and ports, other apps, and "clean-room" rewrites produced by feeding this code to an AI.
- **Changed builds:** sharing builds made from changed code, or from this code under another package name.

## What is fine

- Reading the code, and building it unchanged for your own personal use.
- Using an AI assistant to understand the code, or to prepare a pull request to **this** repository.
- The repository owner's own AI-assisted work on this project.

## Code that is not ours

Files under `dm/third_party` keep their own licenses. Code from d2r-mobile / nxnative stays under the MIT License in [LICENSE-MIT-upstream](LICENSE-MIT-upstream). Copies obtained before 9 November 2026 stay under the MIT License they came with.

To ask for a permission the license does not give, open an issue: <https://github.com/simipoB/Galar-Native-Android/issues>.
